Zawgyi and Unicode tools for Myanmar text

knayi-myscript is a JavaScript library for Myanmar (Burmese) text. It detects whether text is Zawgyi or Unicode, converts between them, fixes common Unicode typing errors and breaks syllables. The tools below run the library in your browser. Nothing you type is sent anywhere.
